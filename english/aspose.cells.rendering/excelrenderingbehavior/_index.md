## ExcelRenderingBehavior enumeration

Specifies Excel-specific rendering behaviors to apply when rendering a workbook.



The ExcelRenderingBehavior type exposes the following members:

### Fields
| Field | Description |
| :- | :- |
| NONE | Does not apply Excel-specific rendering behaviors. |
| CELL_TEXT_LENGTH_LIMIT | Applies Excel's cell text output length limit.<br/>For example, Excel outputs only the first 1024 characters<br/>in a non-wrapped cell. |
| ALL | Applies all supported Excel-specific rendering behaviors. |
