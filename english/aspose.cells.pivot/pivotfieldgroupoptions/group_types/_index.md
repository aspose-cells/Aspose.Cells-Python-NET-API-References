## group_types property


Gets or sets the grouping type for pivot field.

### Remarks 


The order in this property will be ignored.
When specifying multiple group types, base group fields will be inserted in ascending order 
and show group field to row/column region in descending order (Years → Quarters → Months → Days → Hours → Minutes → Seconds).
