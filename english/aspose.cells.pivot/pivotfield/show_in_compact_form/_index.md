## show_in_compact_form property


Gets or sets a value indicating whether this row field uses compact form layout.
Only applies to row fields.

### Remarks 


Compact form is a sub-mode of outline layout.
This setting only takes effect when [`PivotField.show_in_outline_form`](/cells/python-net/aspose.cells.pivot/pivotfield#show_in_outline_form) is true.
