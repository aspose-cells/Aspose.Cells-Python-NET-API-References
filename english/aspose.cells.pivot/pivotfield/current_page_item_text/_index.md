## current_page_item_text property


Gets the display text of the current page item for this pivot field (page field only).

### Remarks 


Returns "(All)" when [`PivotField.current_page_item`](/cells/python-net/aspose.cells.pivot/pivotfield#current_page_item) equals [`PivotItem.AllPageItemsIndex`](/cells/python-net/aspose.cells.pivot/pivotitem).
For other values, returns the string representation of the item index.
