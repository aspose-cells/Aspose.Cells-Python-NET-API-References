## PivotShowValuesAsType enumeration

Represents the calculation type for the "Show Values As" feature of pivot field values.



The PivotShowValuesAsType type exposes the following members:

### Fields
| Field | Description |
| :- | :- |
| NORMAL | Represents raw value, no custom calculation. |
| DIFFERENCE_FROM | Shows the value as the difference from a specified base item. |
| PERCENTAGE_OF | Shows the value as a percentage of a specified base item. |
| PERCENTAGE_DIFFERENCE_FROM | Shows the value as percentage difference from a specified base item. |
| RUNNING_TOTAL_IN | Shows the value as a running total along the specified base field. |
| PERCENTAGE_OF_ROW | Shows the value as percentage of the row total. |
| PERCENTAGE_OF_COLUMN | Shows the value as percentage of the column total. |
| PERCENTAGE_OF_TOTAL | Shows the value as percentage of the grand total. |
| INDEX | Index calculation: (Cell Value × Grand Total of Grand Totals) / (Row Grand Total × Column Grand Total). |
| PERCENTAGE_OF_PARENT_ROW_TOTAL | Shows the value as percentage of its parent row item total. |
| PERCENTAGE_OF_PARENT_COLUMN_TOTAL | Shows the value as percentage of its parent column item total. |
| PERCENTAGE_OF_PARENT_TOTAL | Shows the value as percentage of its parent item total in the specified base field. |
| PERCENTAGE_OF_RUNNING_TOTAL_IN | Shows the value as percentage running total along the specified base field. |
| RANK_SMALLEST_TO_LARGEST | Ranks values from smallest to largest within the specified base field. |
| RANK_LARGEST_TO_SMALLEST | Ranks values from largest to smallest within the specified base field. |
