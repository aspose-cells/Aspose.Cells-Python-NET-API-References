## is_xls_classic property


Gets or sets a value indicating whether to create classic Excel 97-2003 style PivotTable.

### Remarks 


Classic PivotTable uses legacy layout and formatting from Excel 97-2003.
When not explicitly set, the default value is determined by the target workbook file format.
