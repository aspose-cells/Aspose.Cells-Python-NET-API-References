## ShapeDisplayType enumeration

Represents how the application displays shapes in this workbook. Shapes might include charts,
images, and other object data that the application supports.



The ShapeDisplayType type exposes the following members:

### Fields
| Field | Description |
| :- | :- |
| ALL | Indicates that all shapes be shown in the workbook. |
| PLACEHOLDERS | Indicates that the application show placeholders for shapes in the workbook. |
| NONE | Indicates that all shapes be hidden in the workbook. |
